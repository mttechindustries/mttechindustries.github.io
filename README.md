## Current Commercialization Structure

### Lead customer-validation hypothesis — Cognitive Dynamics

Software-first AI integrity and authorized security assessment. The first commercial experiment is a bounded assessment engagement: agreed target and scope, structured evidence, reporting, findings, and remediation discussion. Customer workflow and willingness to pay still require external validation.

### Lead funded-R&D / sensing-validation hypothesis — WoofWizeX-FRS

Patent-filed companion-animal sensing research and validation platform. Existing work includes acquisition, observation, provenance, data-control, and validation infrastructure. Commercial field accuracy, diagnostic performance, medical-alert performance, and veterinary outcomes are not claimed without the required external evidence.

### Alternate higher-value B2B wedge — Seer²

Local-first signal-integrity evaluation. Implemented software and an initial physical audio acquisition path exist; additional physical sensor modalities remain separate development and validation work.

### Evidence-producing support lane — Prediction

Prediction continues accumulating timestamped, resolvable forecast evidence under explicit qualification criteria. Passing tests or simulation does not establish forecast accuracy.
